HOW TO INSTALL
1. Extract the ZIP to a folder.
2. Open chrome://extensions and turn on Developer mode.
3. Click Load unpacked and select the extracted folder.

IMPORTANT
The extension's modules/ent2/userSearch.js still fetches data.json from
https://raw.githubusercontent.com/ddot103/Entryuser/refs/heads/main/data.json
The bundled data.json is a preserved snapshot and is NOT automatically loaded
by the unmodified extension. The extension also uses live playentry.org APIs.
If those services disappear, full functionality is NOT assured.

The archive preserves the earlier extension files without modification.
